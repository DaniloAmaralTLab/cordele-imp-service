# IMP-013 -- DOCX parser adapter: mammoth + style map -> ContentTree

**Status:** INTACT -- gerado 2026-08-24
**Maturidade:** 0 -- Inicial

## Contexto

Implements `ManuscriptParserPort` for `formato=docx` using `mammoth` with a deterministic
style map. Converts DOCX structure → ContentTree (chapters → sections → blocks). Extracts
embedded images via `FileStoragePort`. Any region that cannot be confidently structured
becomes an `UnparsedSegment` (never dropped — local ADR-002).

## Spec de referencia
- SPEC-03 (determinism, block types, UnparsedSegment taxonomy)

## Escopo

Files to create:

- `src/infrastructure/parsing/imp/docx-mammoth.adapter.ts` — implements ManuscriptParserPort for docx
- `src/infrastructure/parsing/imp/docx-style-map.ts` — deterministic mammoth style map (Heading 1 → chapter, Heading 2 → section, etc.)
- `src/infrastructure/parsing/imp/docx-mammoth.adapter.spec.ts` — unit tests with real (minimal) DOCX buffers from test fixtures
