# IMP-016 -- FileStoragePort interface + local-disk adapter

**Status:** INTACT -- gerado 2026-08-24

## Contexto

Implements `FileStoragePort` (defined in IMP-003) with a local-disk adapter for POC.
Key scheme: `emp_<slug>/manuscritos/<manuscritoId>/<original|img-N>.<ext>`.
Tenant slug always comes from `EmpresaContext` — never from caller-supplied input.
A storage failure aborts the import (no manuscript persisted).

- [ ] `delete(key)` removes the file; no-ops silently if already absent (idempotent)
