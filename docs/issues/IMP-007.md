# IMP-007 -- IgnoreSegmentUseCase: persist editorial annotation for unparsed segment

**Status:** INTACT -- gerado 2026-08-24
**Maturidade:** 0 -- Inicial

## Contexto

Addendum endpoint (api-contract.md §8.1): "Ignorar fragmento" in T04 was client-only. This
issue adds the server-side persistence so the ignore annotation survives page refresh.

The use case validates that `segmentoId` exists in `manuscrito.estrutura` (JSONB lookup),
then persists a `SegmentoCuradoria` row. UNIQUE constraint provides idempotency — a second
ignore of the same segment returns 200 instead of 201.

Manuscripts remain immutable (ADR-002): `estrutura` is never modified. The annotation is a
separate mutable record.

Also implements the restore path: `DELETE /manuscripts/{id}/segmentos/{segId}/ignore` removes
the annotation (404 if absent).

Also implements: `GET /manuscripts/{id}/segmentos/ignored` → `{ manuscritoId, ignoredSegmentoIds[] }`.
