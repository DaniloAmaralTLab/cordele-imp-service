# IMP-017 -- OAuth2 JWT guard + scope enforcement + EmpresaContext middleware

**Status:** INTACT -- gerado 2026-08-24
**Maturidade:** 0 -- Inicial

## Contexto

Security layer: JWT Bearer validation (OAUTH2_JWK_SET_URI), scope checks per endpoint
(`imp:write` on mutations, `imp:read` on reads), and `EmpresaContext` population from the
JWT `empresa` claim (RULE-07). Tenant is NEVER read from path/query/body.

Cross-tenant access → 404 (not 403 — never reveals existence of cross-tenant resources).

- `src/infrastructure/auth/imp/empresa-context.middleware.ts` — populates `EmpresaContext` (AsyncLocalStorage) from JWT `empresa` claim before the controller runs
