## Contexto

Core use case: validate format/size → resolve project binding (D-C) → store binary via
FileStoragePort → parse via ManuscriptParserPort → persist immutable Manuscrito → emit
ManuscriptImported. All steps run synchronously in the request (decision D-A). Any step
failure before persistence aborts the import and emits ManuscriptImportRejected.

The use case calls only interfaces (ports), never concrete adapters. Transaction boundary
is at the application service.
