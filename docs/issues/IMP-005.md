# IMP-005 -- Project binding D-C: projetoTitulo (create) + projetoId (validate)

**Status:** INTACT -- gerado 2026-08-24
**Maturidade:** 0 -- Inicial

## Contexto

Decision D-C: the upload request carries exactly one of `projetoId` (existing) or `projetoTitulo`
(create-and-upload). IMP resolves the project through PROJ inbound ports — it never touches
`projeto_editorial` directly. This step runs inside `ImportManuscriptUseCase` before parsing.

Validation: `IF neither OR both → 400`. `IF projetoId and project not found in active empresa → 422`.
`IF projetoTitulo and PROJ.CreateProjetoEditorialUseCase fails → 422`.

## Criterios de aceite

- [x] `neither` (no projetoId, no projetoTitulo) → throws `ImpValidationException(400, urn:cordele:imp:invalid-project-binding)`
- [x] `both` (both present) → same 400 exception
- [x] `projetoTitulo` → calls `CreateProjetoEditorialUseCase.create({ titulo })`, returns new `projetoId`
- [x] `projetoId` → calls `ProjetoEditorialLookup.exists(id, empresaSlug)`, throws 422 if false
- [x] IMP never writes `projeto_editorial` table (verified by inspecting that no Prisma PROJ model import exists)
