# IMP-003 -- Domain aggregate Manuscrito + ContentTree / Block value objects

**Status:** IN-PROGRESS -- Domain types ImpEntity criado, Manuscrito em P2
**Maturidade:** 1 -- Parcial (ImpEntity, ImpStatus implementados; Manuscrito + value objects planejados para P2)

## Contexto

Pure TypeScript domain types (no Prisma, no NestJS decorators) for the IMP bounded context.
`Manuscrito` is the aggregate root (immutable after creation). `ContentTree`, `Chapter`,
`Section`, `Block` (discriminated union), `UnparsedSegment` are value objects. These types
are the canonical shape shared between domain, application, and infrastructure layers.
