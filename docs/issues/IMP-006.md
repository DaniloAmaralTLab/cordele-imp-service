# IMP-006 -- ManuscriptImported + ManuscriptImportRejected in-process events

**Status:** INTACT -- gerado 2026-08-24
**Maturidade:** 0 -- Inicial

## Contexto

In-process events using NestJS `EventEmitter2`. `ManuscriptImported` fires after DB commit
of the manuscrito row (post-commit, within the request). `ManuscriptImportRejected` fires
on format/size/irrecoverable parse errors (before any persistence). No broker, no external
transport (messaging.enabled=false).

## Spec de referencia
- SPEC-09 (event-contracts.md §1)

## Escopo

Files to create:

- `src/domain/imp/events/manuscript-imported.event.ts` — payload type (eventId, occurredAt, manuscritoId, projetoId, editoraId, formato, counts)
- `src/domain/imp/events/manuscript-import-rejected.event.ts` — payload type (eventId, occurredAt, projetoId?, nomeArquivo, reason enum)
- `src/modules/imp/use-cases/import-manuscript.use-case.ts` — emit events via EventEmitter2 (modify IMP-004 deliverable)

## Resultado esperado

Post-import test: `EventEmitter2.emit` called once with `ManuscriptImported` after successful commit.
Post-rejection test: `EventEmitter2.emit` called once with `ManuscriptImportRejected`, never `ManuscriptImported`.

## Criterios de aceite

- [ ] `ManuscriptImported` is emitted AFTER `ManuscritoRepository.save()` resolves (ordering verified in unit test with spy)
- [ ] `ManuscriptImportRejected` is emitted when upload is rejected; `ManuscriptImported` is NOT emitted
- [ ] If transaction rolls back (save throws): no ManuscriptImported emitted
- [ ] `eventId` is a unique UUID per emission
- [ ] `pnpm test` on import use-case spec covers event emission
