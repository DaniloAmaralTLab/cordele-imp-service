# IMP-010 -- ManuscritoRepository port + Prisma adapter

**Status:** INTACT -- gerado 2026-08-24
**Maturidade:** 0 -- Inicial

## Contexto

Implements `ManuscritoRepositoryPort` (defined in IMP-003) with a Prisma adapter that targets
the tenant schema dynamically via `EmpresaContext`. The adapter maps between the Prisma model
(snake_case) and the domain `Manuscrito` aggregate (camelCase).

`save()` is an INSERT only — no UPDATE (immutability). `findById` + `listByProjeto` are
tenant-scoped (always filter by the schema from `EmpresaContext`).
