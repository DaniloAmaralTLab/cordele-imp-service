# IMP-014 -- Markdown parser adapter: remark AST -> ContentTree

**Status:** INTACT -- gerado 2026-08-24
**Maturidade:** 0 -- Inicial

## Contexto

Implements `ManuscriptParserPort` for `formato=markdown` using `remark` (unified ecosystem).
Converts Markdown AST → ContentTree. Headings define chapter/section boundaries. Images
are normalized to `Image` blocks with `storageKey`. Unsupported Markdown constructs become
`UnparsedSegment` with `reason: 'unsupported_markup'`.
