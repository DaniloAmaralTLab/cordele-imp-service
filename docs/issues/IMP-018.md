# IMP-018 -- X-Correlation-Id interceptor + structured JSON logger

**Status:** in-review -- implementado 2026-08-25
**Maturidade:** 0 -- Inicial

## Contexto

Observability: every request carries a `correlationId` (generated if absent from header).
Structured JSON logs include `empresa`, `correlationId`, `manuscritoId` on upload. Parse
diagnostics (formato, tamanhoBytes, totalCapitulos, totalImagens, trechosNaoParseados,
parseDurationMs) are logged as a single structured event after each successful import.

Every response includes `X-Correlation-Id`. Import logs emit structured JSON with parse diagnostics.
