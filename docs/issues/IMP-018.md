# IMP-018 — Correlation id e logs de importação

## Contexto

Toda requisição carrega um `X-Correlation-Id` (gerado quando não vem no cabeçalho), devolvido na
resposta. Falta fechar o ciclo para o suporte: cada importação deve deixar uma única entrada de log
estruturada, e toda resposta de erro deve trazer o mesmo id para cruzar a reclamação do usuário com
os logs.

O interceptor já existe em `src/infrastructure/http/correlation-id.interceptor.ts`. O formato dos
erros está em `docs/services/imp-service/contracts/api-contract.md` §5.

## Checklist

- [x] A resposta sempre carrega `X-Correlation-Id` (gerado quando ausente na requisição)
- [ ] A importação bem-sucedida gera uma entrada de log estruturada, pelo logger do Nest, com
      `correlationId`, `empresa`, `manuscritoId`, `formato`, `tamanhoBytes`, `totalCapitulos`,
      `trechosNaoParseados` e `parseDurationMs`
- [ ] Respostas de erro (ProblemDetail) trazem `traceId` igual ao correlation id da requisição
- [x] O spec do interceptor passa
