# IMP-021 -- Test seed fixtures (6 DOCX/MD files for BDD + scaffold seed data)

**Status:** INTACT -- gerado 2026-08-24
**Maturidade:** 0 -- Inicial

## Contexto

All 6 fixtures referenced in SPEC-08 and BDD scenarios must exist as real files in
`tests/fixtures/imp/`. They are also required as seed data in the M5 scaffold so that
`pnpm test:bdd` can run without manual setup.

The fixture `livro-corrompido.docx` is specifically critical: M3 specs-validate flagged that
this fixture must exist for the `parse-failed → 422` scenario to execute (missing fixture causes
a test error instead of a meaningful assertion failure).

## Spec de referencia
- SPEC-08 (§Dados de exemplo)

## Escopo

Files to create:

- `tests/fixtures/imp/livro-3-capitulos.docx` — minimal real DOCX: 3 chapter headings (H1), 2 chapter texts, 2 embedded PNG images (can be 1x1 pixel), 0 tables. Generated programmatically via `docx` npm package in a seed script.
- `tests/fixtures/imp/livro-com-tabela-complexa.docx` — minimal DOCX with 1 table (grid) that the mammoth style map classifies as `complex_table` → 1 UnparsedSegment.
- `tests/fixtures/imp/livro.md` — Markdown file: H1 + H2 headings, paragraph text, 1 image reference (`![alt](./img.png)`).
- `tests/fixtures/imp/livro.pdf` — any PDF binary (can be 1 byte) for the 415 rejection test.
- `tests/fixtures/imp/livro-51mb.docx` — binary file of 53690000 bytes (> 52428800 cap) for the 413 test. Can be created with `Buffer.alloc(53690000)` in a seed script.
- `tests/fixtures/imp/livro-corrompido.docx` — truncated/corrupt DOCX binary (e.g., empty ZIP header) that causes mammoth to throw an irrecoverable parse error → 422.

Seed script:

- `scripts/seed-imp-fixtures.ts` — generates all 6 fixtures programmatically; idempotent (no-op if files already exist). Run once per developer setup.
- Document the seed command in `backend/README.md` (or `setup-local.md`).

## Resultado esperado

`ls tests/fixtures/imp/` shows all 6 files. `pnpm seed:imp-fixtures` runs without error.
BDD step `When the editor uploads "livro-corrompido.docx"` triggers real 422.
