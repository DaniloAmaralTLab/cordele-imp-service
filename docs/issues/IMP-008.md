# IMP-008 -- ConfirmEstruturaUseCase: advance projeto status to em_composicao

**Status:** INTACT -- gerado 2026-08-24
**Maturidade:** 0 -- Inicial

## Contexto

Addendum endpoint (api-contract.md §8.2): "Confirmar estrutura" in T04 was a no-op on the
server. This issue adds the server action: IMP resolves `manuscritoId → projetoId`, then
calls `PROJ.AdvanceProjetoStatusUseCase.advanceTo({ projetoId, targetStatus: 'em_composicao' })`
via in-process DI.

IMP NEVER writes `projeto_editorial` directly (decision D-C still applies). The call is
idempotent: if the project is already in `em_composicao` or a later status, PROJ returns
success without error.
